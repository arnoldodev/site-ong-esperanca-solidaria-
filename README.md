# Projeto Acadêmico - Website ONG Esperança Solidária

Este repositório contém o projeto desenvolvido para fins de estudo universitário, focado na consolidação de **HTML5 Semântico**, acessibilidade e validações nativas.

---

## Contexto Acadêmico
* **Objetivo:** Projeto prático de Desenvolvimento Web para a faculdade.
* **Foco:** HTML5 semântico, acessibilidade (WCAG), formulários nativos e organização de arquivos.
