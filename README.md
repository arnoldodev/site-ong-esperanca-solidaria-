# Projeto Acadêmico - Website ONG Esperança Solidária

Este repositório contém o projeto desenvolvido para fins de estudo universitário, focado em **HTML5 semântico**, **CSS3**, acessibilidade e validações nativas de formulário.

---

## Contexto Acadêmico
* **Objetivo:** Projeto prático de Desenvolvimento Web para a faculdade.
* **Foco:** HTML5 semântico, CSS3 (variáveis, Flexbox, Grid e responsividade), acessibilidade (WCAG) e formulários nativos.

---

## Estrutura do Projeto

```text
Site ONG/
├── assets/      # Imagens
├── css/         # Estilos (style.css)
└── html/        # Páginas
    ├── index.html        # Página inicial
    ├── projetos.html     # Projetos da ONG
    ├── cadastro.html     # Cadastro de voluntários
    └── componentes.html  # Guia com os componentes visuais (badges, alertas, toasts, modal e botões)
```

---

## Como abrir

Abra o arquivo `html/index.html` no navegador, ou use a extensão **Live Server** do VS Code.

---

## O que foi usado no CSS

* Variáveis no `:root` para cores, fontes e espaçamentos
* Grid de 12 colunas e Flexbox
* 5 breakpoints para celular, tablet, notebook e telas grandes
* Menu hambúrguer e dropdown feitos só com CSS
* Modais com `:target`
* Feedback visual nos campos do formulário (válido e inválido)
